Tooltip ​

Pure-CSS tooltip revealed on hover or keyboard focus — no positioning library.

Basic usage ​

Deploy to productionShown belowTo the leftTo the right
template
<RTooltip content="Deploy to production">
  <RButton size="sm">Deploy</RButton>
</RTooltip>

<RTooltip placement="bottom" content="Shown below">
  …
</RTooltip>

Hover the examples — or Tab to them — to reveal. The trigger exposes aria-describedby linked to the tooltip's role="tooltip" element; colors auto-invert per theme.

WARNING

CSS-only tooltips clip inside overflow: hidden containers and don't flip at viewport edges. For those cases, pair with a floating-ui-based solution.

API ​

PropTypeDefault
contentstring—
placement'top' | 'bottom' | 'left' | 'right''top'

Slots: default (trigger), content (rich tooltip)
